Decision Stack Protocol

Governed AI
State to decision

The LLM receives current asset state from the semantic model, not loose dashboard text.

Structured
Consequence reasoning

Time, causality, intervention options, do-nothing paths, and optimization are included so the model explains downstream effects, not just the alert.

Decision-ready
Safety boundary

The LLM drafts and explains. It should not directly control equipment, override alarms, or create work orders without human approval.

Guardrail

Baseline Analytics

Normal operating envelopes are created per asset class using temperature, vibration, load, pressure, utilization, and energy signatures.

Anomaly Detection

Hybrid rules and ML detect abnormal drift, trend deviation, and repeated operating patterns associated with failure precursors.

Model Governance

Each model has documented training data, validation metrics, version history, drift monitoring, retraining cadence, and explainability notes.
